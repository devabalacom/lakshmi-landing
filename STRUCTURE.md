```

│   └── style.css          # Дополнительные стили
├── js/

├── images/                # Папка для изображений
├── pages/
│   ├── about.html         # О компании
│   └── contacts.html      # Контакты
├── services/              # 9 страниц услуг
│   ├── chekhly-tenty.html
```

## 🏠 Главная страница (index.html)

### Блоки:
1. **Header** - навигация + телефон
2. **Hero** - УТП + 2 CTA кнопки
3. **Каталог** - 9 карточек направлений
4. **Преимущества** - 4 карточки
5. **О компании** - краткое описание
6. **Блок захвата** - прямой контакт
7. **Footer** - контакты, ссылки

## 📄 Страницы услуг (9 шт)

### Единая структура каждой страницы:
1. **Hero** - заголовок + описание + CTA
2. **Описание** - что решает услуга
3. **Области применения** - где используется
4. **Технические характеристики** - материалы, защита, фурнитура
5. **Возможности** - брендирование, лекала, усиление
6. **Схема работы** - 5 шагов (контакт → расчет → договор → производство → доставка)
7. **FAQ** - 3-4 вопроса по услуге
8. **Контактный блок** - телефон, email, быстрый переход

### Список услуг:
1. **Чехлы, укрытия, тенты** (chekhly-tenty.html)
   - ПВХ, Oxford, Tarpaulin
   - Защита оборудования, контейнеров, стройплощадок

2. **Спецодежда** (specodezhda.html)
   - Огнеупорная, антистатическая
   - ГОСТ, ТУ соответствие

3. **Тактическое снаряжение** (tactical.html)
   - Cordura, Ripstop
   - Рюкзаки, подсумки, чехлы

4. **Медицинский текстиль** (medical.html)
   - Антимикробные ткани
   - Халаты, чехлы для оборудования

5. **Интерьерный B2B текстиль** (interior.html)
   - Огнестойкий для отелей, ресторанов
   - Шторы, обивка, драпировки

6. **Транспортный текстиль** (transport.html)
   - Жд, авиа, спецтехника
   - Обивка, чехлы, органайзеры

7. **Агропромышленный** (agro.html)
   - Укрытия для ферм, теплиц
   - УФ-защита, влагостойкость

8. **Пожарозащита МЧС** (fire.html)
   - Негорючие материалы
   - Палатки, тенты для экстремальных условий

9. **Чистые помещения** (cleanroom.html)
   - Антистатика для фармы
   - Пыленепроницаемость, стерильность
