Описание и применение

Где востребовано и какие задачи решает.

Производим огнезащитный текстиль для МЧС, пожарных подразделений и промышленных объектов с повышенными требованиями пожарной безопасности. Негорючие палатки быстрого развёртывания, огнеупорные тенты и защитные экраны, изолирующие чехлы для оборудования. Материалы сертифицированы по ГОСТ Р 53272 и проходят испытания на огнестойкость в независимых лабораториях.

Вопросы по направлению

Нет в списке — позвоните или напишите.

Какой класс огнестойкости обеспечивают используемые материалы? +

Используем материалы классов горючести Г1 (слабогорючие) и НГ (негорючие) по ГОСТ 30244, воспламеняемости В1 по ГОСТ 30402. Доступны ткани на основе стекловолокна, базальтового волокна, силиконизированного стекловолокна — рабочая температура до +1000°C. Для МЧС — сертифицированные материалы с протоколами испытаний.

Производите ли быстроразворачиваемые укрытия для МЧС? +

Да. Изготавливаем палатки и укрытия, разворачиваемые 2–4 людьми за 5–10 минут, с лёгкими каркасами из алюминиевого сплава или стекловолокна. Применяются как штабы управления, пункты первой помощи и временные укрытия при ликвидации ЧС. Поставка в упаковке с транспортировочными сумками.

Соответствуют ли изделия ГОСТ Р 53272 (пожарное снаряжение)? +

Да, работаем по требованиям ГОСТ Р 53272 и смежным нормативам. Предоставляем паспорт качества с указанием класса огнестойкости материала, протоколы испытаний в аккредитованных лабораториях. По запросу — полный пакет для включения в реестр МЧС.

Есть ли опыт поставок для государственных структур? +

Да. Работаем с государственными заказчиками по 44-ФЗ и 223-ФЗ. Среди клиентов — промышленные предприятия с подразделениями пожарной охраны, логистические комплексы. Предоставляем полный комплект документов: техническое описание, паспорт качества, счёт-фактура, накладная.

Насколько долговечны огнеупорные изделия при регулярной эксплуатации? +

Базальтовые и стекловолоконные изделия — практически неограниченный срок службы при отсутствии механических повреждений. Органические огнезащитные ткани (Nomex, Kevlar) — 5–10 лет при правильном хранении. Рекомендуем ежегодный визуальный осмотр и проверку целостности покрытий.

Производите ли огнезащитные экраны для промышленного оборудования? +

Да — это один из наших ключевых продуктов. Изготавливаем термозащитные экраны, искрозащитные занавеси, изолирующие кожухи для сварочных зон, плавильных печей и трубопроводов с высокотемпературными средами. Форма и крепёж — по чертежам заказчика.
