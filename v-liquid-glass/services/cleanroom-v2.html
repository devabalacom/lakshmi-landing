Описание и применение

Где востребовано и какие задачи решает.

Производим специализированный текстиль для чистых помещений: антистатическая одежда для персонала, пыленепроницаемые перегородки и занавеси, чехлы для оборудования. Соответствие классам ISO 4–8 по ГОСТ Р ИСО 14644. Ткани сертифицированы на пылевыделение, электростатику (ESD) и химическую стойкость к растворителям.

Вопросы по направлению

Нет в списке — позвоните или напишите.

Для каких классов чистоты ISO подходят ваши изделия? +

Наши ткани и изделия сертифицированы для использования в чистых помещениях ISO 5–8 по ГОСТ Р ИСО 14644-1. Для классов ISO 4 и выше рекомендуем специальные ламинированные ткани с нулевым пылевыделением. Класс совместимости уточняется по технической документации на ткань.

Соответствуют ли изделия требованиям ГОСТ Р ИСО 14644 и GMP? +

Да. Работаем с тканями, прошедшими тестирование на пылевыделение в соответствии с ISO 14644-5. Предоставляем паспорта на материалы с характеристиками частицеотделения. По запросу — полный пакет документов для фармацевтических производств, включая процедуры квалификации поставщика (GMP Annex 15).

Какой класс ESD (антистатики) обеспечивают изделия? +

Используем ткани с поверхностным сопротивлением 10⁵–10⁹ Ом — диапазон ESD-защитных материалов по IEC 61340-5-1. Для производств полупроводников обеспечиваем класс S1 (менее 10⁷ Ом). Антистатические свойства проверяются и подтверждаются протоколом испытаний.

Выдерживают ли ткани обработку изопропиловым спиртом и другими растворителями? +

Да. Ткани на основе полиэстера и нейлона с антистатической обработкой устойчивы к ИПС, этанолу, ацетону и слабым кислотам. Для агрессивных сред (кислоты, щёлочи, органические растворители) рекомендуем ламинированные ткани PTFE или Nomex с химически стойким покрытием.

Как проверяется пыленепроницаемость швов? +

Швы проклеиваются антистатической термолентой или выполняются ультразвуковой сваркой — это исключает сквозное пылепрохождение. Критические швы проверяются на герметичность методом аэрозольной тест-дымки. По запросу — протокол испытаний швов с указанием класса пылезащиты.

Производите ли одежду для персонала чистых помещений? +

Да: комбинезоны, халаты, бахилы, чехлы для обуви и головные уборы из антистатических и малопылящих тканей. Пошив по стандартным размерным рядам или по индивидуальным меркам. Упаковка в двойные стерильные пакеты, маркировка по размерам и партиям — по запросу.
