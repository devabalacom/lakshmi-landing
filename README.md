# Лендинг "Лакшми" - Производство технического текстиля

Современный одностраничный лендинг для компании по производству технического текстиля.

## 🎯 Особенности

- ✅ Адаптивный дизайн (mobile-first)
- ✅ Tailwind CSS для стилизации
- ✅ Плавные анимации и переходы
- ✅ Рабочие прямые контакты (tel/mailto)
- ✅ Оптимизирован для SEO
- ✅ Быстрая загрузка
- ✅ Accessibility (WCAG 2.1)

## 📦 Структура

```
lakshmi-landing/

```

## 🚀 Запуск

### Вариант 1: Локальный сервер (рекомендуется)

```bash
# Python 3
cd lakshmi-landing
python3 -m http.server 8000

# Или Python 2
python -m SimpleHTTPServer 8000

# Или Node.js (npx http-server)
npx http-server -p 8000
```

Откройте http://localhost:8000

### Вариант 2: Прямое открытие

Просто откройте `index.html` в браузере.

## 🎨 Кастомизация

### Цвета

Основные цвета в Tailwind (можно изменить в `tailwind.config.js` или через CDN настройки):

- Primary: `blue-600` (#2563eb)
- Secondary: `gray-900` (#111827)
- Success: `green-500` (#10b981)
- Text: `gray-700` (#374151)

### Шрифты

По умолчанию используется системный шрифт-стек. Для добавления кастомного шрифта:

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
```

Обновите `font-sans` в HTML.

### Изображения

Добавьте изображения в папку `images/` и обновите ссылки в HTML:

```html
<img src="images/hero-bg.jpg" alt="Производство текстиля">
```

Сайт использует прямой контакт через `tel:` и `mailto:`. Если позже добавите форму, подключайте backend отдельно и не возвращайте старую логику как есть.
